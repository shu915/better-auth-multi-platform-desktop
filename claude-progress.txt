## 決めたこと
- 範囲: メールのログイン、プロフィール、退会 → 動いたら Google
- 配布は自分の Mac だけ(公証なし)
- 識別子 com.shu915.authpractice.desktop、アプリ名 Auth Practice
- Web の口は /api/mobile/* をそのまま使う(名前の一般化は、後で考える)
- 秘密は Rust と Keychain だけ。JS には、Keychain を触るコマンドも、deep link の権限も渡さない。JS の権限は event の購読(listen、unlisten)だけ
- Web の URL は AUTH_WEB_URL、Go の URL は AUTH_API_URL で、ビルド時に埋め込む。デバッグの既定は http://localhost:3000 と http://localhost:8080、リリースは https 必須(AUTH_WEB_URL=… AUTH_API_URL=… npm run tauri build)

## .app を試すとき(deep link は、ビルドした .app を /Applications に入れたときだけ届く)
- ビルド(署名付き。人が自分のターミナルで): IDENTITY=$(security find-identity -v -p codesigning | sed -n 's/.*"\(Apple Development:[^"]*\)".*/\1/p' | head -1) して APPLE_SIGNING_IDENTITY="$IDENTITY" npm run tauri build -- --debug --bundles app(デバッグビルドは localhost に繋げる。リリースは https 必須)。詳しくは CLAUDE.md の「署名」
- 入れ替え: アプリを終了して rm -rf "/Applications/Auth Practice.app" && ditto src-tauri/target/debug/bundle/macos/"Auth Practice.app" "/Applications/Auth Practice.app"(署名を保つため ditto)。target/ 側の .app も登録されるので、lsregister -u で外す(CLAUDE.md の「署名」)。メールのリンクが古い .app に渡ると、古い画面が出る
- ログを見る: "/Applications/Auth Practice.app/Contents/MacOS/tauri-app" をターミナルから起動(デバッグビルドは [auth] link outcome: … を出す。秘密は出さない)
- 偽リンクを試す: open -g "betterauthmulti:///?state=zzz&code=$(date +%s)"(code は毎回変える。同じ code は 2 回目から無視される。-g がないと open が前に出す)
- 署名付きなら、ビルドし直しても Keychain の許可は聞かれない(実機で、署名付きで 2 回ビルドして確認)。署名なしのバイナリ(tauri dev など)は、聞かれる。「常に許可」を選ぶ

## 既知の注意
- tauri dev はビルドのたびに Keychain を聞かれる(署名なし)。ログインと退会の確認は、署名付きの .app で
- Web の /api/auth/expo-authorization-proxy の open redirect(モバイルと共通の未対応)
- 引き換えが失敗すると、そのリンクは使い切りで、再試行できない(もう一度リンクを頼む。設計どおり)
- リリースビルドは、診断を何も出さない(段階 6 で見る)
- Cargo.lock で rust-ini を 0.21.1 に固定している。0.21.3 は ParseOption に項目を足し、tauri-plugin-deep-link 2.6.2 の Linux 用のコードがコンパイルできなくなる(CI は Ubuntu で落ちるが、Mac では気づかない)。deep-link の新しい版が出たら、固定を外せるか試す(cargo update -p rust-ini で、CI が通るか)
- Dependabot の glib(Linux 用、Tauri が固定)は、更新できないと失敗扱いになる。Mac には関係ない
- 署名の証明書(無料の Apple Development)は、2027 年 10 月 27 日に切れる。更新したら、Keychain の許可を、もう一度聞かれることがある
- 残りのリモートブランチの削除(あとでまとめて)
